# Smart Bug Analysis

## Project Overview

Smart Bug Analysis is a Data Analyst project used to analyze software bugs and understand bug status, priority, project-wise bugs, and resolution time.

## Tools Used

- Excel
- SQL
- Python
- Power BI

## Key Analysis

- Total number of bugs
- Open and closed bugs
- Priority-wise bug analysis
- Project-wise bug count
- Average resolution time
- Assignee-wise bug analysis
- High-priority and unresolved bugs
- Interactive Power BI dashboard


## Dashboard

![Smart Bug Analysis Dashboard](smartbug_analysis.png)
The Power BI dashboard provides a clear visual summary of bug status, priority, project distribution, and resolution time.

## Project Outcome

This project demonstrates data cleaning, data analysis, SQL querying, Python analysis, Excel analysis, and Power BI dashboard creation.
